# Contributing

1. Create a branch.
2. Add or update tests for behavior changes.
3. Run `npm run verify` to run the build, full test suite, and credential-free benchmark manifest validation.
4. Keep verification statuses evidence-bound and avoid invented confidence scores.
5. Document any new provider's failure behavior and provenance fields.

Bug reports should include the input claim, redacted evidence, expected status, actual status, and provider/model metadata when relevant.
